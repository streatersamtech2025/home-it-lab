# User Management Lab

## Overview

This lab demonstrates basic Windows 11 user account administration within a virtual machine environment running on macOS.

## Objective

Learn how to create, manage, and modify local user accounts in Windows 11.

## Environment

- Host OS: macOS

- Virtualization Software: UTM

- Guest OS: Windows 11 Home

- Lab Computer Name: HELPDESK-LAB

## Tasks Completed

### Created Local User Accounts

Created the following local user accounts:

- JohnUser

- SarahUser

- HelpDeskAdmin

### Modified User Permissions

Changed the HelpDeskAdmin account from a Standard User to an Administrator account.

### Reviewed Account Management

Verified user account creation and reviewed available account management options.

## Skills Demonstrated

- Windows 11 Administration

- User Account Management

- Permission Management

- Basic Help Desk Procedures

- Technical Documentation

## Lessons Learned

User accounts can be created and managed through Windows Settings. Different permission levels can be assigned depending on business requirements. Administrator accounts have elevated privileges compared to standard users and should be assigned carefully.

## Lab Results

Successfully created and managed multiple local user accounts in Windows 11 and assigned administrator privileges to a designated support account.

This lab provided hands-on experience with common help desk responsibilities involving user account creation, account management, and permission assignment in a Windows environment.
