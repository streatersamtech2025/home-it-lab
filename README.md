# Windows 11 Home IT Lab

## Overview

This project documents a Windows 11 Home virtual lab built on macOS using UTM virtualization software.

The lab was created to develop hands-on IT support skills including user administration, networking, software installation, troubleshooting, and technical documentation.

## Technologies Used

- Windows 11 Home
- macOS
- UTM Virtualization
- GitHub
- GitHub Desktop
- Command Prompt

## Labs Completed

### User Management
- Created local user accounts
- Assigned administrator permissions
- Practiced account management

### Networking
- Used ipconfig
- Performed ping testing
- Conducted DNS lookups with nslookup

### Software Installation
- Installed and configured applications
- Verified software functionality

### Troubleshooting
- Diagnosed and resolved common issues
- Documented troubleshooting procedures

## Skills Demonstrated

- Windows Administration
- User Account Management
- Network Troubleshooting
- DNS Testing
- Technical Documentation
- GitHub Version Control
- Virtualization

## Project Structure

Documentation contains all lab documentation.

Screenshots contains supporting images captured during lab activities.
